# Scope and third-party attribution

This repository currently publishes documentation and integration examples only.
The BackendSecurityKit library, executable, dependency wheels, certificates,
credentials and runtime database are not included in this documentation preview.

The example imports the complete BackendSecurityKit project; it generates fresh
temporary demonstration credentials at runtime rather than including any key or
token literals. It cannot run without the complete project's securitykit package.

Application documentation/examples use the root MIT LICENSE. Tencent/WeKnora's
complete upstream license is retained in licenses/WeKnora-LICENSE.txt. The fixed
reference commit and independently implemented differences are in UPSTREAM.md.
Original legal attribution is retained and is not personal information belonging
to this repository owner. This is not an official Tencent distribution.

The full portable package separately includes CPython, cryptography, grpcio and
their dependencies and notices; those runtime components are not distributed in
this repository preview.
